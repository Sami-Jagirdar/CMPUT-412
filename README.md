# CMPUT 412 - Experimental Mobile Robotics

A project-based course dealing with the design and implementation of mobile robots to accomplish specific tasks.

Duckiebots were used for every project

Each project has been documented along with the source code used in their respective folders formatted as: "exercise-{id}".

Throughout the course, we focused on topics and technologies such as:
- Kinematics of robots
- Sensor Technologies and Sensor Data processing
- Control Systems based on feedback and real-time programming
- ROS2
- Computer Vision
